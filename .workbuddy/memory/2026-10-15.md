## pnpm 环境重要发现（长期有效）
- 本机 pnpm 12 的 isolated 模式顶层 junction 链接会静默失败（pnpm 退出码 0 但不建链接，node_modules 只剩 .pnpm）。
- pnpm 12 配置已迁移到 pnpm-workspace.yaml，.npmrc 里的 node-linker 不生效。
- 解决方案：pnpm-workspace.yaml 中加 `nodeLinker: hoisted`，项目已配置，后续 pnpm install 直接可用。
- 清理含 junction 的旧 node_modules 时注意：pnpm 硬链接使新旧目录文件共享 inode，需先停掉 dev server 才能删净。

## 列表页数据 bug 修复（重要教训）
- 图片列表 / 用户管理页表格无数据的根因：模板绑定 `:columns="cloneColumns"`，但 cloneColumns 初始化为空数组且从未同步（search-table 页的 cloneColumns 是列设置功能专用，不适用）。
- 修复：直接绑定 computed `:columns="columns"`，删除 cloneColumns。
- 两页搜索栏按钮由竖排（a-space direction="vertical"）改为横排：去掉竖排 space 和 height:84px 的 divider，按钮区改 flex="180px"。
- 教训：新页面照抄 search-table 的 cloneColumns 模式前要先确认其用途；fetchData 的 catch 吞错误导致问题隐蔽，排查时优先看模板绑定。
